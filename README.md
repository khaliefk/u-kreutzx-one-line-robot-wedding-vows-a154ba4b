## What it does

`main.py` writes a single line of wedding vows for a robot couple to
`/output/entry.txt`. The line is a real vow, in classic wedding cadence,
with the machine twist landing in the last few words: "my one and only"
nods at binary, "in full charge and in low battery" mirrors "in sickness
and in health", and the vow ends on a factory reset instead of death.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The entry is one line, 1-160 characters, plain UTF-8 text.
